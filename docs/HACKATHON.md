## About the challenge

PayPal already moves money for millions of people and businesses, every day, all over the world. This hackathon opens that platform up and asks what happens when you put AI behind the wheel: new agents, new ways to pay and get paid, tools nobody's built yet.

A global online hackathon for developers, designers, founders, students and builders. **There are no prescribed problem statements and no tracks.** Build an agent, an app, an automation, a new payment experience, a business tool, a social product, or something new.

**The one fundamental requirement: the project must meaningfully use both PayPal and AI.**

Why join:

- Build something ambitious with PayPal and AI.
- Experiment with new ways people, businesses and AI agents interact with money and payments.
- Win part of **$69,750** in total prizes.
- Put the project in front of PayPal judges, developers and the community.
- Learn PayPal APIs, AI tools, agents, automations and new development workflows.
- Join alone or as a team; start something new or meaningfully advance an existing project.

## Requirements

### What to build

Build or update an application that integrates the **PayPal developer platform (free sandbox environment)** with an AI tool, model or platform of your choice.

Optional sponsor tools: AG Grid, APIMatic, Astropods, Bryntum, Channel3, Elastic, KERNEL, Postman, Render, Zapier. PayPal provides access to select AI sponsor tools, but using them is not required. Any AI tool works, as long as **PayPal integration is central** to the project.

The project should:

- Meaningfully integrate at least one PayPal technology, API, SDK, product or developer capability.
- Meaningfully incorporate AI into the experience or functionality.
- Demonstrate a working prototype or proof of concept.
- Be documented well enough for judges to understand and evaluate it.
- Comply with the Official Rules.

Individual or team. New or existing projects are fine, as long as meaningful progress is made during the hackathon.

### What to submit

- [ ] **Project** built with the required developer tools and meeting the requirements above.
- [ ] **Text description** of the project's features and functionality.
- [ ] **Functional demo** judges can actually run or interact with, either:
  - clear, complete setup and run instructions in the repo, or
  - a hosted demo URL.
  - A design mockup, static prototype or non-functional demo does **not** qualify.
- [ ] **Tools**: name the models or AI services used and explain how each was used.
- [ ] **Public code repository** on GitHub, GitLab or Bitbucket:
  - all source code, assets and instructions needed to run the project;
  - public and open source, with a **license file visible at the top of the repo** (About section).
- [ ] **Demo video**:
  - **under 3 minutes** (judges need not watch past that);
  - shows the project working on the device it was built for;
  - on **YouTube, public**, link on the submission form;
  - no third-party trademarks or copyrighted music/material without permission.

## Judging criteria

| Criterion | What judges ask |
|---|---|
| Technological Implementation | How thoroughly and skillfully does the project use the PayPal Developer Platform and AI tools? Is it a genuine, working, non-trivial implementation? |
| Design | Does it deliver a complete, coherent product experience, not just a technical proof of concept? |
| Potential Impact | Does it make a credible, specific case for solving a real problem for a real audience, and does what's demonstrated actually address it? |
| Innovation / Idea | How creative and novel is the concept, and how does it differ from existing ones? |
| Presentation | Does the video clearly show the project working end to end? Does the pitch say what problem is solved, who it's for and why it matters? Is it easy to follow? |
